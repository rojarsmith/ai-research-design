## 已排除的舊說法

| 容易看到的說法 | 本研究處理 |
| --- | --- |
| Delaware LLC 每年 US$300 | 2026 官方修法及現行說明為 US$400；舊表單和舊文章仍可能顯示 US$300 |
| 外國人美國 LLC 一律要 BOI | 以 FinCEN 現行豁免為準；不得連帶推導 IRS／銀行豁免 |
| 境外電商台灣登記門檻 NT$48 萬 | 自 2025 年起改為 NT$60 萬；某些舊 FAQ 尚留舊值 |
| 個人年度結匯 US$500 萬、公司 US$5,000 萬 | 現行一般額度為 US$1,000 萬及 US$1 億；特殊款項另論 |
| 零收入免報 5472；出資不用揭露 | 必須查看關係人交易及 Part V，而非只看銷售收入 |
| 第一次遲報一定免 US$25,000 罰款 | 合理原因與 FTA 的適用須按具體法律及處罰類型判定 |
| 美國 LLC 所得全部是台灣海外所得 | 看收入性質、在臺履約、分類和納稅主體，不能直接套標籤 |
| 在臺管理就自動適用已生效 PEM | 區分未生效的特定制度與其他已存在的來源／營業義務 |

## 專業人士需要回答的問題

1. 既有 LLC 的歷年成員、稅務選擇、所有人居留日數與應用稅年度是什麼？
2. 各筆投入、分配、借款、報銷、開辦費與關係人交易，應在 5472 哪裡揭露？舊年度是否完整且及時？
3. 有沒有美國 ECI、FDAP、州來源收入、實體／經濟 nexus 或需扣繳的付款？
4. 台灣如何分類 LLC 與實際報酬？是否有台灣來源收入、CFC、營業登記或境外電商義務？
5. 台美分類／年度／納稅人不一致時，外國稅額扣抵能否使用，何時使用，由誰使用？
6. 公司海外帳戶、最高餘額、帳戶法律所在地與 FBAR 申報人是什麼？
7. 年度委任包含哪些表格、州別、台灣判定、更正與通知答覆？誰保存完整送件證據？

在每年一月結帳、四月送 IRS、成立週年月份前及擴張新市場前，重查相應機關頁面與該年度表格版本。一般報告無法替尚未提供的營收、產品、客戶地區與海外帳戶作最後判定。
