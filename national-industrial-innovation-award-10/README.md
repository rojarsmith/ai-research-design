# 第10屆經濟部國家產業創新獎報名研究

本目錄用於整理官方規定、報名材料及逐次修訂申請書。

- `input/`：原始申請書、個人與公司資料、公開來源、使用者補件。全部排除 Git。
- `output/`：各版申請書、缺件清單、查核紀錄及版面檢查。全部排除 Git。
- 僅本說明、作業規則與 `.gitignore` 可納入 Git；不在上述兩個目錄之外存放個資或其衍生內容。

官方網站：https://service.moea.gov.tw/EE514/tw/niia

每次補資料後，以 input 的最新證據更新申請書。每輪使用獨立的 `vNNN_YYYYMMDD_HHMMSS` 目錄，保留所有舊版本；缺件及證據對照表隨版保存。不得將推測寫成個人實績，不得代簽或代替推薦人確認推薦內容。
