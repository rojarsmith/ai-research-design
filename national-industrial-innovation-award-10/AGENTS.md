# 本目錄作業規則

- 所有個資、公司研究資料、下載來源、擷取文字、暫存、生成腳本、申請書及缺件紀錄均只存入 input 或 output，兩者不得加入 Git，不得使用 git add -f。
- input 原始檔保留不變。更新資料使用新檔名，不覆盖既有來源。
- 每次產出先建立新的 output/vNNN_YYYYMMDD_HHMMSS 目錄，若路徑存在則停止或另取新版本，不得覆蓋舊申請書。
- 先盤點 input 新增資料，依原始表單與最新官方規定填寫。缺資料時將具體欄位、所需證據及填寫方式列入該版缺件清單。
- 以個人類申請書所載類組為準，不自動改成公司組織類申請。公開公司成果只能作公司背景，除非 input 有個人參與與貢獻證據。
- 區分已證實事實、公司自述、待確認事項；不虛構學經歷、績效、推薦理由、簽章、日期或完整身分證字號。
- 每版記錄來源、修改、未完成項目及檢查結果。提交前清除待補標記與書寫說明，完成逐頁版面檢查、簽章、附件及 PDF 大小檢查。
- 本工作流程為本地準備，網站送出與對外寄信須有使用者另行授權。
