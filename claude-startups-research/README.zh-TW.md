# Claude Startups 申請研究與 HMI Studio 適用性

研究日期：2026 年 10 月 12 日，Asia/Taipei。完整研究以繁體中文提供；[English overview](README.md)。

**目前不宜把 EDT HMI Studio 的申請評估為高機率通過。** 產品已有具體 AI 功能與公開展示，但使用者確認它是任職 EDT 時開發、將商業化的公司產品。申請主體的資格，比產品介紹寫得漂亮更重要。建議先由有公司授權的人詢問企業內部新產品是否適用，同時查核既有 Max 20x 訂閱可領的 API 額度。

## 現行福利與舊文章的落差

[官方計畫頁](https://claude.com/programs/startups)目前表示免費一年 Claude Team 與一次性 US$1,000 API credit 已超出容量，並將重新審查申請；已領取者可繼續使用。現有會員仍有 Startup Stack、Applied AI office hours 與活動。**新申請獲准與取得免費 Team／US$1,000 是兩件事，後兩項不能納入確定可得的預算。**

| 項目 | 2026 年 10 月 12 日的判讀 |
| --- | --- |
| 免費一年 Team、US$1,000 一次性額度 | 現行 FAQ 已說明超出容量；沒有公布恢復時間 |
| Startup Stack | 合作夥伴優惠的最高合計標示為 US$45,000；並非現金或全部可用的 Claude API 額度 |
| VC 路徑 | 合作 VC 的被投公司可能取得最高 US$100,000 額外 API 額度；並非一般申請人自動享有 |
| 審查時間 | 官方目標為一週；屬目標，不是核准或時程保證 |

來源：[官方計畫 FAQ](https://claude.com/programs/startups)。

你提供的 [AI 郵報文章](https://www.aiposthub.com/claude-startups-application-eligibility-claim-guide/)採用 2026 年 10 月 8 日的資訊，仍把免費 Team 與 US$1,000 當成核准公司的基本福利。**福利段落已過時**；公司身分一致、如實說明產品用途的準備方向仍可參考。

[10 月 6 日官方公告](https://claude.com/resources/articles/were-expanding-the-claude-startups-program-to-help-founders-build)也保留最初福利描述。這次是同一週內的政策變動，不能僅以「官方公告」四字就把舊福利當成現在仍可領。

## 資格與申請主體

10 月 6 日的[官方擴大計畫公告](https://claude.com/resources/articles/were-expanding-the-claude-startups-program-to-help-founders-build)列出「最近五年成立，或最近兩年獲得資金」。以本次查核日粗估，分別約為 2021 年 10 月以後、2024 年 10 月以後；實際日期邊界與 funding 定義須以送件表單及官方確認為準。當前公開 FAQ 未重新完整列出這項時間規則，也未明示取消它。

官方確認不必有 VC 投資，自籌新創可申請。正式[計畫條款](https://www.anthropic.com/startup-program-official-terms)則要求申請代表有權約束公司；評估包含業務進展、投資／資金與 Claude 整合／用量，最終由 Anthropic 判定。因此，下列資訊需要分開填：

- **申請公司**：真正負責產品及服務的公司或組織。
- **產品品牌**：EDT HMI Studio／HMI Studio，不等同一間新成立公司。
- **產品開始或 Alpha 發布日期**：不能取代公司成立日期。
- **資金事件**：列明日期、類型與實際接受資金的主體，請官方確認是否屬於規則所指的 funding。

## HMI Studio 能不能申請

EDT 的[公司沿革](https://www.edtc.com/about-edt/)與 [Shinden 的供應商資料](https://www.shinden.co.jp/english/products/supplier/edt.php)都記載成立於 1994 年。**以 EDT 原公司申請，成立時間這條路不符合上述公告條件。** 若近兩年有合格資金事件，或官方願意接納企業內部新事業，才可能有其他路徑；目前沒有足以確認這兩點的資料。

| 真實情況 | 建議路徑 | 通過可能性的判斷 |
| --- | --- | --- |
| EDT 內部新產品，沒有已確認的合格近期資金事件 | 先詢問資格，交代母公司與產品關係 | 現有證據不支持稱為高機率 |
| EDT 近兩年取得官方認可的 funding | 提供事件及申請主體，先確認成熟公司是否適用 | 有待官方認定；資金日期本身不保證接受 |
| 實際由近五年成立的新公司經營產品 | 提供成立資料、產品經營／IP 授權與母公司關係 | 較符合時間條件；仍須核實公司獨立性與其他資格 |
| 只有新品牌、網域或內部部門 | 維持實際公司身分 | 這些變更不會改變公司成立年份 |

不用為了目前已暫停的福利另設空殼公司。若公司本來就規劃分拆新事業，才值得另評估經營主體、授權、資金及官方是否接納企業支持的新創。

[HMI Studio 網站](https://www.hmistudio.io/)已提供 AI 助理、Alpha 下載與影片，足以支持「有具體產品」的敘述。它不能證明公司符合新創資格，也不能證明已有付費客戶。詳見[專案證據與申請補強](research/project-assessment.zh-TW.md)。

## 最能提高申請品質的方法

沒有公開核准率或評分權重可用來計算成功百分比。以下方法的作用是減少身分與證據問題；不會把不符合資格的申請變成合格。

1. **先解決資格。** 使用[英文資格詢問草稿](application-kit.zh-TW.md)，請官方確認 EDT 內部新產品、近期資金或真實新公司哪一條適用。若答覆不適用，轉向一般 API／企業合作，不重複用不同帳號送同一產品。
2. **整理公司與產品關係。** 法律公司名、產品名、網站與聯絡信箱互相對得上。`hmistudio.io` 與 `edt.com.tw` 不同網域時，直接說明前者是產品網站、後者是公司信箱，不必為此假裝獨立公司。
3. **準備可檢查的成果。** 一個短示範、兩個可重現案例、產品階段、真實試用回饋。業務進展用日期和可核對資料呈現；尚無營收就直接寫尚未商業發布。
4. **準確描述 Claude 用法。** 區分 Claude 協助開發、產品透過 OpenRouter 使用 Claude，以及未來是否要直連 Claude API。只把真正完成的功能寫成已提供。
5. **清楚說明要用資源解決什麼。** 例如驗證草圖轉畫面、工具操作正確率、多語文字和長專案修改。量化預算使用實測 token 與任務次數，不捏造流量或效益。
6. **資格成立後一次完整送件。** 從[官方 Console 入口](https://platform.claude.com/offers/startups-application)登入正確組織，按當時實際欄位填寫，留存提交內容、日期與回覆。未見登入後表單，因此本研究的準備表不是官方必填欄位清單。

若超過官方目標一週仍沒有回覆，可在同一支援對話提供提交日期及組織資訊詢問進度。[官方支援方式](https://support.claude.com/en/articles/9015913-how-to-get-support)是帳號內 Get help／支援訊息；沒有查到可以保證快速核准的窗口。

## 你已有 Max 20x 的立即可用路徑

截至本次查核，[官方 Max 與 Team 每月 API 額度說明](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans)列出 **Max 20x 每月 US$200**，與 Startups 核准無關。條件是訂閱有效且狀態正常、新訂戶滿七天，並擁有 Console 組織的 Owner、Admin 或 Billing 權限。

領取步驟：網頁版 Claude → **Settings → Billing → API credits → Link organization** → 選擇或建立 Console 組織 → 閱讀額度條款並完成連結。先確認組織歸屬與公司使用安排：每個訂閱只連一個組織，組織也只收一個訂閱的額度，之後變更需找支援。

額度依帳期更新、未用餘額不累積，可供第一方 Claude API 使用，**不能支付 OpenRouter 或互動式 Claude Code 的用量**。沒有其他餘額時額度耗盡會停止 API 請求；已有購買額度／自動儲值則可能繼續扣用。個人實際是否已出現領取入口，需在自己的帳號確認。以上同出自[官方額度說明](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans)。

對 HMI Studio 而言，可先做獨立的第一方 API 評測，再決定是否新增直連 provider；不需先獲得 Startups 資格。**目前產品走 OpenRouter，領完額度也不會自動抵掉現在的產品用量。**

## 地區與經營範圍

Taiwan 列在[官方支援地區](https://www.anthropic.com/supported-countries)；規則也限制不支援地區的實際使用者、成立／總部所在地與控制關係。[Startups 條款](https://www.anthropic.com/startup-program-official-terms)另外限制在指定地區經營、或計畫向該地區人士提供服務的申請人。

EDT 的公開[供應商資料](https://www.shinden.co.jp/english/products/supplier/edt.php)提到中國東莞生產基地，因此公司申請需要釐清實際申請法人與 AI 使用地點／服務市場。這是本案具體需確認的事項，不能僅憑有海外工廠就代替 Anthropic 作出資格結論，也不能把只在台灣研發當成當然豁免。
