# MCU Embedded HMI Ecosystem Comparison

Research date: October 12, 2026, Asia/Taipei.

This research compares the eight requested offerings: SquareLine Studio, TouchGFX, DWIN DGUS, LVGL Open, Winstar CAN smart displays, Levetop UART TFT controllers, ARTERY AT32, and HMI Studio. The full report and supporting research are in Traditional Chinese.

The first decision is where graphics, application behavior, and communications run. These offerings cover different layers: UI authoring tools, graphics frameworks, MCU platforms, display controller ICs, and integrated display modules. Some can be combined, so an overall ranking would conceal the architecture tradeoffs.
