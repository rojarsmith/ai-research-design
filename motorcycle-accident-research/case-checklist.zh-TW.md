## 立即辦理

- [ ] 如仍有疼痛或症狀惡化，立即就醫／回診；告知醫師事故發生經過和身體症狀。
- [ ] 備份行車紀錄器原始檔（至少事故前後各數分鐘），另存兩份，不要覆蓋記憶卡。
- [ ] 寫下自己記得的時間線：出發方向、車道位置、號誌、對方位置與轉向、閃避、摔倒點、傷勢。標示記不清楚之處。
- [ ] 聯絡原處理警察單位，要求優先保全／調閱周邊監視器、輕軌列車前鏡頭、站體影像和其他可用影像；詢問是否已調閱及是否需要補書面申請。
- [ ] 查找事故附近店家、住戶、車輛或目擊者；請對方保留原始影像並留下聯絡方式。不要自行進入私人場所或擅取影像。
- [ ] 將事故補充說明書面交警方，要求納入事故調查紀錄；留存副本或收件證明。
- [ ] 通知自己強制險保險公司事故已發生，記下案件編號；確認自己的保單只有強制險，並查明承保公司與效期。
- [ ] 詢問對方強制險承保公司／理賠窗口，提出自己受傷的強制險人傷申請；請對方說明是否另有第三人責任險及承保公司。

## 車輛與現場

- [ ] 現場位置全景、各方向道路、號誌、標誌、標線、軌道／路面、視線遮蔽物照片。
- [ ] 機車全車四面照、車牌、損傷遠照與近照；安全帽、衣物、手機等受損物另拍照。
- [ ] 拍攝並保存原始檔；備份至不會自動刪除的雲端或外接儲存裝置。
- [ ] 未修車：先估價、留分項明細並通知對方／保險；如有安全急迫性，先完整蒐證再修。
- [ ] 修車時：要求車行分列零件、工資、拆裝、檢測與拖吊；留估價單、維修單、發票／收據、付款證明、拆下零件照片及修後照。
- [ ] 保留事故時衣物、安全帽、護具；不要清洗或丟棄明顯擦痕物品，直到拍攝保存。

## 人身傷害與支出

- [ ] 診斷證明、急診／門診病歷、影像檢查、處方箋、復健及回診紀錄。
- [ ] 醫療收據、藥費、醫療器材、就醫交通費等按日期整理。
- [ ] 請假／扣薪證明、薪資單、雇主證明或營業收入紀錄。
- [ ] 若需他人照護，保留醫療端對照護需求的說明、照顧日期／時數及支出紀錄。
- [ ] 建立症狀與生活影響日誌：疼痛、睡眠、工作受限、活動限制與治療日期，按事實記錄。
- [ ] 詢問對方強制險理賠窗口：醫療費項目、各細項限額、應備文件及尚缺資料。
- [ ] 詢問對方是否另有機車第三人責任險（體傷及財損）、承保公司、理賠案號與理賠窗口；保單未確認前不推定有投保。
- [ ] 記得：對方強制險可能處理你作為另一車駕駛人的體傷申請，但不處理你的車損、精神慰撫金或全部民事損失；提交強制險申請不等於承認責任比例。

## 警方資料與期限

- [ ] 事故現場取得當事人登記聯單，核對事故日期、地點、雙方車牌及處理單位。
- [ ] 事故滿7日後，申請現場圖與照片；若中央系統無法申辦，洽原處理單位。
- [ ] 事故滿30日後，申請初步分析研判表。
- [ ] 初判表到手後，核對基本資料、事故因素及與現場圖／影像／筆錄是否一致。
- [ ] 有具體不服理由時，查詢事故所在地車鑑會流程；事故日起6個月內提出鑑定申請期限。
- [ ] 如評估過失傷害告訴，記下知悉對方身分日起6個月告訴期限；民事請求時效請儘早個別核對。

## 溝通與和解

- [ ] 重要溝通採文字並留存日期、對象、內容；不要在社群公開對方個資或未遮蔽的病歷／保單。
- [ ] 對方若主張你有過失或向你求償，要求具體項目、證明、承保公司及理賠窗口；不要口頭承認責任比例。
- [ ] 治療未完成、影像未釐清、賠償項目未盤點前，不簽終局結清或放棄請求權條款。
- [ ] 和解／調解文件須逐項寫明金額、付款期限、是否包含強制險、醫療後續、車損、刑事撤告安排與保留的請求。
