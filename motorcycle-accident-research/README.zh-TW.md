# 機車事故證據與求償研究

**研究日期：2026-10-14（台灣時間）**  
**事故敘述：** 當事人騎機車，主張自己在車道內綠燈直行；對向機車疑似提前左轉侵入車道，當事人為閃避於跨越輕軌路段滑倒受傷、機車受損。目前初判表未出。當事人自己的機車險只有強制險，對方至少有強制險，是否另有任意險未知。

> 本文件是待證據補齊的研究工作底稿，不是已認定的肇責結論或個案法律意見。文章作者的說法、官方規範、法院個案與本文件推論分開標註。事故所在地尚未提供；涉及地方申請窗口、輕軌影像保管單位時，以下以高雄輕軌作為情境提醒，請依實際地點確認。

## 先做這些事

若事故剛發生或尚未完成：

1. **先就醫並完整描述事故與傷處。** 留存診斷證明、急診／門診病歷、檢查報告、收據、處方箋、回診紀錄和醫療交通支出。若疼痛、麻木或頭部症狀加重，及時回診。醫療紀錄應如實寫明「閃避對方後摔車」及發生時間，切勿要求醫師替你判定肇責。
2. **立刻書面請警方保全調閱影像。** 聯絡事故登記聯單上的原處理單位，要求在事故調查中調閱並保全：路口／沿線監視器、輕軌列車前方行車影像、站體影像（若有）、附近店家或住戶監視器。提供精確日期、時間範圍、行進方向、路口／輕軌站／路段和你的聯絡資料，請警方告知是否已調閱及影像保存期限。不要只等之後申請初判表；部分影像可能很快覆寫。自己也立即備份行車紀錄器原始檔，勿剪輯覆蓋。
3. **把事故經過補充進警方紀錄。** 若原筆錄不完整，可儘快向承辦員警提交一頁時間順序說明，寫清楚號誌、你的車道與方向、對方左轉軌跡、雙方距離、你採取的閃避動作、摔倒位置、是否接觸、傷勢、目擊者與可能影像。只寫親身所見與記憶，不推測對方心理或車速；保留收件證明。
4. **保存現場與車損證據。** 拍攝事故點遠景、號誌／標線、車道配置、輕軌軌道與路面、視線遮蔽物、機車全車和所有損傷近照、衣物／安全帽破損、擦地痕及傷勢。記錄原始檔、拍攝時間與拍攝位置。未修車先取得估價與明細並通知對方及保險；若因安全必須先修，先充分拍照、請車行保留拆下零件、開立分項估價／維修單／收據並拍修後照。
5. **通知自己的強制險保險公司及對方強制險公司。** 你自己的強制險一般不賠你這位駕駛人自己的傷（它是賠車外第三人／乘客）；但這是兩車事故，若能證明你的受傷是另一台有投保機車所致，可向對方強制險申請人身傷害給付，不以對方有過失為前提。它不賠機車修理費、精神慰撫金或收入損失。請對方提供承保公司、保單／車號資訊與理賠窗口；不清楚對方是否另有第三人責任險時，不要假定有或沒有。
6. **先不要簽終局和解或認責文件。** 初判表未出、治療可能未完、影像尚未確認時，先不要簽「所有損害一次結清」或放棄其餘請求的文件。若收到對方索賠或警方通知，按事實處理並把文件交自己的保險公司／法律專業者檢視。

## 本案最關鍵的證明問題

這不是已確認的「對方左轉違規造成事故」，目前只是你的事故敘述。要釐清責任，至少要查明：

- **號誌與路權：** 你所在方向當時是否確為綠燈、左轉車是否有專用時相／左轉箭頭或禁止左轉標誌。要以影像、號誌時相資料、現場配置與警方蒐證核對。
- **對方動線：** 對方何時開始左轉、是否已侵入你的車道、位置與距離、是否有足夠避讓空間。
- **閃避與倒地關係：** 你是否為避免迫切碰撞而緊急閃避、失衡摔倒位置與時間，車損／路面痕跡及影像能否連成時間線。
- **接觸與事故紀錄：** 是否有任何車身接觸、擦撞或對方停留；即使無直接接觸，也要讓警方明確記錄你主張的因果過程，避免被簡化成單車自摔。
- **損害連結：** 醫療紀錄的時間與傷勢、衣物／安全帽、車損、工作損失等能否支持受傷與事故間的關聯。

因為你描述的是「閃避後摔倒」，**影像及警方現場調查尤其重要**。只靠事後口述，容易在是否為單一機車自摔、是否涉及對方車輛、因果關係及各自注意義務上產生爭議。不要誇大或補造細節；儘快把記憶寫下來並標示不確定處。

## 你目前的保險位置

| 損失／保障 | 可能處理方式 | 重要限制 |
|---|---|---|
| 你自己的醫療支出 | 先以健保就醫；確認本案屬兩車事故後，向對方強制險申請符合標準的傷害醫療費 | 強制險醫療給付每人每事故上限新台幣20萬元，細項有法定限額；需證明是本次事故所致。你自己的強制險通常不承保本車駕駛人本人傷害 |
| 失能（若治療後有符合標準的遺存障害） | 向對方強制險依失能等級申請 | 須符合醫療與失能標準；自2026-07-01起給付標準調整，事故日適用規定須核對 |
| 機車修理費、手機／安全帽等物損 | 向依法應負責的對方請求；若對方有第三人責任險，由其保險公司依保單處理 | 強制險不賠財損。對方是否有任意第三人責任險未知，請直接詢問並取得書面資訊 |
| 工作收入損失、看護、必要交通費 | 納入民事損害清單並留病歷、薪資／請假、看護必要性、收據等證據；強制險部分項目有狹義標準 | 是否必要、合理、與事故有因果關係及責任比例，須個案審查；不要把強制險給付和民事賠償混為一談 |
| 精神慰撫金 | 有身體／健康受侵害時，可能依民法第195條請求 | 沒有固定行情公式；法院視傷勢、治療與生活影響、事故經過、兩造身分資力等核定，且可能受過失相抵影響 |
| 你自己對對方的責任風險 | 目前無任意第三人責任險時，若被認定有責，超過你強制險承保範圍的對方體傷及財損可能要自行負擔 | 強制險不是替自己賠對方的第三人責任險；若對方主張你也有過失，先轉交你的保險公司（強制險公司不等於民事責任代理人）並尋求專業協助 |

**對方保險待確認：** 對方「至少有強制險」代表可先確認對方強制險承保公司並提出你的人傷申請；不代表其一定有第三人責任險。可請對方提供任意險承保公司、理賠案號及理賠人聯絡方式。承保資料可請警方在事故處理過程協助確認，或透過強制險服務窗口核對；不要公開張貼完整身分證號、保單號或病歷。

## 初判表與後續程序

- 事故滿 **7日**後，可依規定向處理警察機關申請現場圖、現場照片；事故滿 **30日**後，可申請道路交通事故初步分析研判表。有人受傷且警方到場的案件通常可用警政署線上系統，系統適用條件與案件進度以官方頁面及原處理單位為準。
- 初判表是警方的初步分析，通常不裁定肇責百分比，也不是法院最後判決。取得後與現場圖、影像、筆錄及醫療資料一起核對。
- 對初判原因有具體異議，可評估事故發生日起 **6個月內**向事故所在地車輛行車事故鑑定委員會申請鑑定；先整理爭點與證據，鑑定費用及地方流程依該委員會規定。
- 若有人受傷且希望追究過失傷害刑事責任，告訴乃論通常有知悉犯人起 **6個月**期間；民事侵權求償時效通常有「知悉損害及賠償義務人起2年、事故起最長10年」規則。具體起算與個案適用請儘早向律師或法律扶助確認，勿等初判或鑑定結果才留意期限。

## 損害清冊範本

建議建立試算表，一筆一列，保留「預估」與「已支出」的區別：

| 醫療交通 | 日期、起訖、就醫原因、票據／收據；若無票據記錄計算方式 |
| 看護費 | 醫囑或病歷中看護必要性、期間、實際付款或照護紀錄 |
| 工作損失 | 雇主請假／扣薪證明、薪資單、所得或營業資料、醫囑休養期間 |
| 機車維修 | 修前全景與特寫、估價單、拆換零件、工資分列、發票／收據、付款證明、修後照片 |
| 其他財損 | 安全帽、衣物、手機等購買證明、損壞照片及合理修復／重置資料 |
| 事故證據 | 警方案號、當事人登記聯單、現場圖／照、影片原始檔、目擊者聯絡方式、對話紀錄 |

機車零件求償可能涉及新品換舊品折舊，但不宜照網路文章的單一「年限滿了就只剩1/10」公式自行認定。法院判決通常把零件費與工資分開、查車齡並按適用折舊規則計算；必要工資一般不按零件折舊方式計。代步費亦非只要有支出就必然全額准許，須證明合理必要與期間。

## 強制險對你的實際影響

國泰文章正確提醒強制險不賠車損；但你描述的是兩台有牌機車參與的事故，而不是已確認只有你一台機車的「單一事故」。強制險法定受害人定義與交叉理賠規則可能使你向對方機車的強制險申請自己的體傷給付，即使肇責尚未定或對方否認過失。請儘快向對方承保公司報案並提出申請，保險人會依事故車輛、人員、因果關係和法定給付標準審核。若警方紀錄把事故列作單一自摔而未記入對方機車的疑似侵入及閃避過程，先要求補充事故陳述並提出影像／證人線索。對方強制險不會替你修車；財損及超出強制險的人身損害，須依民事責任、證據和可能存在的任意第三人責任險處理。

建議詢問對方／承保公司四件事：

1. 對方強制險的承保公司、有效保期及理賠案號為何？
2. 你作為另一車駕駛人，依本事故資料申請傷害醫療給付需要哪些文件？
3. 對方是否另有機車第三人責任險（體傷／財損）、承保公司及理賠人？
4. 你這案的醫療收據、診斷、交通／看護費等逐項給付標準、細項限額、申請方式與缺件為何？

## 資料使用原則

本研究以台灣法規、警政／主管機關資料、強制險基金及法院裁判為主要核驗依據。保險公司可說明其承保商品與理賠窗口，但其商品宣傳不是獨立法律結論；法律事務所或理賠網站的文章僅作為待查核線索。資料日期為2026-10-14；法規、給付標準及申辦流程可能變動，送件前重新確認官方現行頁面。
