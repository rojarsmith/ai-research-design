# ADR-0016：多幣別帳簿、稅務批次、預扣稅與轄區稅務外掛

## 狀態

**提議中（Proposed）** · 2026-10-05 · 範圍：情境 1（自用），優先實作台灣居民外掛。**這是工程政策，不是稅務建議。** 在依據外掛的輸出進行申報之前，必須由稅務顧問確認每一條規則；下文中的每個稅率與門檻都只是當下的快照，每個稅務年度都須重新驗證。

## 背景與問題陳述

目前的工作假設是：擁有者為台灣稅務居民、以 TWD 記帳，同時在 IBKR 以 USD 交易、在加密貨幣交易場所以 USDT 或 USDC 交易，並在台灣券商以 TWD 交易。截至目前，設計只寫了「FX 採事件發生時的匯率；基礎幣別為 TWD」以及「稅務批次（tax lot）透過轄區外掛處理（US wash sale 僅適用於美國納稅人）」。`TaxLot` 雖然在部位模型中被提及，卻從未被定義；沒有選定任何批次方法；源頭預扣稅也沒有對應的帳本事件。而年度申報，正是自行交易者真正需要帳本的地方。

對台灣居民而言的重點（研究 [08](../../research/08-risk-security-ops-compliance.zh-TW.md)、[11](../../research/11-taiwan-market-localization.zh-TW.md)；凡有註明之處，法條文字已於 2026-10-05 在 law.moj.gov.tw 查核）：

| 主題 | 外掛必須支援的內容 |
|---|---|
| 海外所得 | 依所得基本稅額條例第 12 條，非台灣來源所得應計入基本所得額，除非該戶全年合計低於新台幣 100 萬元。第 13 條對基本所得額超過扣除額的部分課徵 20%（法定基準為新台幣 600 萬元，依消費者物價指數（CPI）調整並每年公告；請確認該稅務年度的金額）。在 IBKR 持有之美股的利得與外國股利是常見項目 |
| 美國股利 | 非美國人適用 30% 的美國預扣稅（台灣與美國之間沒有所得稅協定），且須在券商處備有 W-8BEN。放空美股時支付的替代股利（payment in lieu）屬於成本 |
| 台灣股利 | 納稅人可選擇將股利併入綜合所得，並按 8.5% 計算可抵減稅額（每戶上限新台幣 8 萬元），或按 28% 分開計稅（所得稅法第 15 條）。外掛會同時計算兩種方式 |
| 二代健保補充保險費 | 股利所得須計收補充保險費（全民健康保險法第 31 條）；扣費義務人對單次給付達門檻以上者予以扣取（依相關施行規定為每次新台幣 2 萬元）。費率由主管機關公告（自 2021 年起為 2.11%；請確認現行費率） |
| 台灣上市證券與期貨 | 個人的利得不課徵所得稅；交易稅已納入規則包（[ADR-0012](ADR-0012-security-master-rules-packs-and-calendars.zh-TW.md)） |
| 加密貨幣 | 目前沒有專門法規明定個人加密貨幣利得的所得分類；在境外交易場所實現的利得可能被視為海外所得。外掛依交易場所列報已實現利得，分類則留給顧問判斷 |
| FX | 年底數字必須以 TWD 表示，並附上有文件記載的換算匯率。匯款至境外券商受個人每年結匯額度的限制（在銀行辦理、無須核准者每年 500 萬美元；外匯收支或交易申報辦法第 4 條），此屬營運事項，而非稅務事項 |

美國納稅人需要 wash sale 追蹤以及不同的報表；其他居住地則需要各自的外掛。

## 決策驅動因素

- 帳本是稅務數字的單一來源；不從券商 PDF 重新輸入。
- 已實現損益必須能與各券商自己的數字核對，因此批次方法必須與券商一致。
- 可重現：對過去年度的報表重新執行時，會得到相同的結果。
- 依轄區可插拔；核心中不含任何台灣專屬的內容。
- 低成本：批次在 Phase 2a（約 0.2 PM），台灣居民外掛在 Phase 3c（約 0.3 PM）。
- 不宣稱提供稅務建議。

## 考慮的選項

1. **在帳本中記錄稅務批次與預扣稅事件，再以轄區外掛產生以申報幣別表示的年度摘要。**
2. **僅使用券商的稅務文件**（IBKR 年度對帳單與 1042-S、台灣券商對帳單），帳本中不記錄批次。
3. **匯出至第三方投資組合稅務工具。**
4. **完整的稅務引擎**，計算應納稅額並填寫申報書。

## 決策結果

**選定選項：1。** 它重用帳本已經記錄的事件，讓批次與券商保持一致，並止於摘要，因此不會代替擁有者計算任何應納稅額。選項 2 無法將多家券商、交易場所與幣別整合成單一的 TWD 視圖；選項 3 會多出一次個人財務紀錄的資料匯出；選項 4 等於以軟體形式提供稅務建議。

### 多幣別帳簿

- 現金**依幣別**持有。換匯是明確的 `FxConversion` 事件，包含兩邊的分錄（legs）、匯率、手續費與來源；入金、出金與轉帳則是 `CashTransfer` 事件，並附上匯款參考編號。
- 匯率來自 `fx_rate` 資料集（[建議架構](../../architecture/recommended-architecture.zh-TW.md) §3.1）：臺灣銀行牌告匯率、中央銀行新台幣對美元收盤匯率、FRED H.10 以及 IBKR 對帳單匯率，每一筆都帶有 `license_tag`、`as_of_ns` 與 `known_at`。損益使用事件發生前的最新匯率；每日評價與稅務報表使用該轄區所宣告的匯率規則；對帳則使用券商的匯率。
- 穩定幣是商品（以 USD 評價的部位），而不是現金（[ADR-0013](ADR-0013-risk-gate-and-three-path-kill-switch.zh-TW.md)）。
- 排程器依日曆年加總 `CashTransfer` 的結匯金額，並在達到年度結匯額度的 80% 時發出警示。

### 稅務批次

`TaxLot` 定義於[建議架構](../../architecture/recommended-architecture.zh-TW.md)的 §4.5：

| 欄位 | 意義 |
|---|---|
| `acquired_ts_ns`, `acquired_trading_date` | 批次開立的時間（成交、公司行動或轉入） |
| `quantity_open`, `quantity_unit` | 帶正負號的剩餘數量；空頭批次為負值 |
| `cost_total`, `currency` | 以商品幣別計算的成本，**包含**佣金與手續費 |
| `fx_rate_to_base`, `fx_rate_ref`, `cost_total_base` | 依轄區規則取得的取得時匯率、該匯率來自哪一筆 `fx_rate` 資料列，以及 TWD 成本 |
| `lot_method` | `FIFO`（預設）、`AVERAGE_COST` 或 `SPECIFIC_ID`，**依帳戶設定，以與券商一致** |
| `adjustments` | 改變該批次的公司行動（分割、股票股利、減資） |
| `wash_sale_adjustment` | 僅在美國納稅人外掛啟用時使用 |

批次由帳本事件（`TaxLotOpened`、`TaxLotClosed`）開立與關閉，從不直接編輯。公司行動透過與調整部位相同的公司行動事件來調整批次。

### 預扣稅與源頭扣繳

`WithholdingTax` 事件記錄在源頭預扣的稅款（金額、幣別、稅率、轄區、相關的股利或利息事件）。台灣股利被扣取的二代健保補充保險費也以相同方式入帳，但使用其專屬的類型。替代股利、借券費用與保證金利息則是各自獨立的成本事件（[ADR-0012](ADR-0012-security-master-rules-packs-and-calendars.zh-TW.md)）。

### 轄區外掛（`tp_tax`）

| 外掛 | 輸出 |
|---|---|
| `tw_resident`（Phase 3c） | 針對一個日曆年，以 TWD 表示並註明所採用的匯率規則：依類型區分的海外所得（各券商與各交易場所的已實現利得、外國股利、利息），並標示新台幣 100 萬元的每戶門檻檢驗結果；台灣股利，並計算兩種課稅方式；已扣取的補充保險費；已預扣的外國稅款；各交易場所的加密貨幣已實現利得（未分類）；以及已實現損益與各券商年度對帳單的核對 |
| `us_taxpayer`（僅在擁有者為美國人時） | wash sale 調整、每個批次的短期與長期利得 |

報表是記帳的輔助工具。每份報表都會註明其匯率來源、批次方法，以及其內容不構成稅務建議。

### 影響

**正面**

- 跨券商、交易場所與幣別的單一 TWD 視圖，由每日對帳的同一份帳本產生。
- 批次與各券商一致，因此已實現損益可以逐行核對。
- 顧問取得的是完整、可重現的輸入，而不是一疊對帳單。
- 匯款額度與穩定幣曝險在演變成問題之前就能被看見。

**負面**

- 稅務規則、門檻與稅率會變動；每一項都需要像規則包一樣每年檢查。
- 與券商一致的批次方法，可能與稅務顧問偏好的方法不同；外掛報告的是券商實際的做法。
- 加密貨幣的分類仍懸而未決，因此加密貨幣部分是原始資料，而非結論。
- 帳本中有更多事件類型需要永久維護其版本。

### 確認

- 性質測試（property tests）：未平倉批次的總和等於部位；關閉一個批次絕不會改變另一個批次；換匯在入帳匯率下保持價值守恆。
- 年終測試：由批次計算出的已實現損益，與各券商的年度數字在註明的容許誤差內相符。
- 外掛的門檻與稅率存放在附有日期、帶有 `verified_at` 的設定中，每年檢查一次。

### 重新檢視時機

- 擁有者的居住地或美國人身分改變，或有公司實體開始交易。
- 台灣立法規範加密貨幣利得的課稅方式，或美台避免雙重課稅安排生效並改變預扣稅率。
- **T1：** 為其他使用者處理稅務申報，本身就是受監管的服務；不在範圍內。
